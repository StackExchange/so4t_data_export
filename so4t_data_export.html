The export runs in this browser. Your access token stays in this page and is sent only to the API for the instance you enter.

Enterprise: your site URL. Basic or Business: https://stackoverflowteams.com/c/TEAM-NAME

Use a token with permission to read the data you want to export. Private fields such as email appear only when your token can access them.
